## Scientific status

This is an expository framework preprint and has not been peer reviewed. It systematizes standard operator-theoretic and heat-kernel constructions; it does not claim a new general theorem in spectral geometry.

## Core distinctions

- compact carrier versus compact resolvent;
- compact resolvent versus trace-class heat evolution;
- abstract diagonal realization versus finite-dimensional elliptic geometry;
- equivariant eigenspace labels versus perturbative or physical stability.
